# Bootstrap Agent Dompis

Sebelum membaca dokumen proyek lain atau mengubah file, baca [HANDOVER.md](HANDOVER.md) penuh. Kemudian baca [AGENTS.md](AGENTS.md), PRD aktif yang dirujuk handover, serta bukti tugas dan verifikasi Git aktual. AGENTS adalah instruksi proyek kanonis; file ini hanya pengarah untuk Claude Code.

Laporkan checkpoint, versi PRD, status implementasi, pekerjaan parsial, blocker dan satu langkah lanjut sebelum menulis. Pilih skill proyek dari [indeks](docs/skills-index.md) bila sesuai tugas. Sumber tetap dilindungi; skill terpasang tidak memberi izin implementasi, DDL, deploy atau perluasan fitur.
