## 2. Data rules
- All approved original scalar values, including mapped values and generated fields, go into cold `legacy_payload` to preserve original classifier/metric baseline; restrict or omit disallowed PII according to policy. Original full backup encrypted offline with access and retention controls; explicit exclusion manifest, never silent deletion. Never copy relational arrays as columns.
- `reported_date_dt` is a parallel backfilled TIMESTAMP companion per source comments; inspect actual definition and backfill status. Use UTC MySQL session for TIMESTAMP export; string fields need verified source timezone (WIB assumption not sufficient). Preserve fractional precision where supported; reject invalid/zero dates, record nulls and conflicts.
- `operational_bucket` is described as STORED GENERATED in source comments; read value, do not write back to legacy. Inspect actual expression/migrations and port shared business rules. Preserve prior raw value in archive; unknown normalized only under signed mapping. `status_update` is local workflow, not canonical lifecycle.
- Archive-only does not mean safe to omit from reporting. For each retained menu trace field usage in legacy SQL/JS, decide typed promotion vs derived rule or intentional retirement; add schema migration before implementation if required. `status_update`, `pending_dompis`, `sqm_update_reason`, local flags and historical SLA statuses are priority gates. No per-ticket JSONB filtering in hot reports without measured/approved design.
- New fields absent in legacy (source_segment, service_id, classification_id, source_updated_at, source raw TTR etc.) NULL unless equivalent source evidence approved. Set origin=legacy, migrated_at, source_endpoint/hash/first_source_seen_at NULL, rule_version explicit e.g. legacy-import-v1, version=1, quality_flags as applicable. UUID is stable across replay. `created_at/updated_at` local commit times not original reported date.
- Verify status/closed date consistency. If lifecycle=open but old closed_at populated, preserve old closure in archive; do not discard or clear before documented reconciliation. If ambiguity persists use unknown/quarantine rather than violating constraint.
- Long legacy IDs up to 100 characters allowed only if canonical format valid; upstream exact lookup restricted to 32. Manual record eligibility separate, cannot pretend it is live.
- If actual schema adds columns, extend this matrix; dry-run fails closed for unknown columns until disposition reviewed.
