# Performance standards
Initial p95 targets: detail 200ms, list 350ms, overview/rekap 1s, Semesta 31 days 2s. Conditional freshness target 95% within 5 minutes subject to upstream contract. Not measured results. Benchmark 1.2m and 3.5m representative synthetic tickets, 20/80/200 concurrent users, narrow and global scope, hot/cold cache, ingestion concurrent, realistic geography and dates. Record hardware, DB version, dataset, query plans, p50/p95/p99, throughput, error rate, CPU/RAM, disk latency/IOPS, WAL, locks and pool saturation. Use isolated PG and EXPLAIN (ANALYZE, BUFFERS) for safe SELECT; production plain EXPLAIN first. Compare baseline and changed index write cost; reject regressions or document accepted tradeoff. Avoid full table fetch, N+1, deep offset, unbounded exports; use keyset and SQL aggregation. Tune batch/pool/timeouts with measured results; no premature cache/partition. Dedicated PG storage SSD recommended if available; verify actual hardware. Stop tests on production load impact.
