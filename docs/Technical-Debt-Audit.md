# Technical debt audit — initial hypotheses
Source-Audit.md contains archive observations, not current local or production verification. Investigate excessive indexes, wide raw/projection duplication, repeated ingestion, string date conversion, inconsistent SQL/JS KPI, per-row queries, unbounded pagination, connection/lock contention, HDD I/O and unsafe secret handling. For each item record source path/line, actual query fingerprint, plan, rows scanned, latency, frequency, impact, proposed greenfield replacement, test and status. Never copy query text as implementation; redact literals. Prioritize data corruption/integrity and access leaks before speed. Validate on local checkout and registered DB. No claim of current bottleneck until measured.
